Create a new idea. Returns the generated slug. Before calling, ALWAYS use list_ideas first and scan the existing names/slugs for one that overlaps the requested topic — duplicate ideas fragment context and history, and the user almost always wants to land in an existing idea rather than create a near-copy. If a likely match exists, use get_idea_by_slug to confirm and either reuse it or surface it to the user before creating. Only call create_idea when no overlapping idea is found. Use update_idea_by_slug afterwards to set status/summary if needed.
